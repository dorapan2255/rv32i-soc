# 32-bit ALU

## 功能

`alu`是组合逻辑模块，根据`alu_op`对两个32-bit操作数执行算术、逻辑、比较或移位运算。
模块不包含时钟和内部状态。

## 接口

| 信号 | 方向 | 宽度 | 说明 |
|---|---|---:|---|
| `a` | input | 32 | 第一个操作数 |
| `b` | input | 32 | 第二个操作数 |
| `alu_op` | input | 4 | 运算选择 |
| `result` | output | 32 | 运算结果 |

## 支持运算

| `alu_op` | 运算 | 表达式 |
|---|---|---|
| `0000` | ADD | `a + b` |
| `0001` | SUB | `a - b` |
| `0010` | AND | `a & b` |
| `0011` | OR | `a \| b` |
| `0100` | XOR | `a ^ b` |
| `0101` | SLT | `$signed(a) < $signed(b)` |
| `0110` | SLL | `a << b[4:0]` |
| `0111` | SRL | `a >> b[4:0]` |
| `1000` | SRA | `$signed(a) >>> b[4:0]` |

移位量只使用`b[4:0]`，范围为0–31。SLT和SRA使用有符号解释；其他逻辑和移位操作按
位向量处理。不支持的`alu_op`输出零，保证组合块对所有输入都有确定赋值，不推断锁存器。

## 验证范围

`alu_tb`覆盖正常加减法、溢出回绕、逐位逻辑、有符号比较、逻辑/算术右移、最大移位量
和非法操作码。测试使用确定输入与期望值进行自动比较，并生成`waveforms/alu.vcd`。
